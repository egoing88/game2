# Stone Sprint

A small browser game inspired by classic prehistoric side-scrolling action.

Open `index.html` directly, or serve the folder with any static web server.

Live version: https://egoing88.github.io/game2/

## Controls

- Move: `A` / `D` or arrow keys
- Jump: `Space`, `W`, or up arrow
- Attack: `J` / `K`
- Pause: `P`
